# App icon assets

`app-icon-source.png` is the source selected for the DSH Mobile launcher icon. Generated assets are produced by:

```powershell
python .\scripts\generate-app-icons.py
```

The script updates Android legacy, round, and adaptive launcher icons together with the PWA 192 px, 512 px, and maskable icons. `app-icon-preview.png` shows the launcher masks used for visual review.
